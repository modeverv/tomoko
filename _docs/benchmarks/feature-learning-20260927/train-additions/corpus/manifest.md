# Synthetic training additions: targeted versus general

These 640 utterances were newly written by an AI author for the 2026-09-27 feature/learning experiment. They are not actual conversations, user logs, Japanese Daily Dialogue, or any other external corpus. Only the previous 240-example corpus and its public experiment predictions were read. No blind directory or blind evaluation example was accessed by this author.

## Development evidence

The previous `runtime_config/codex` student, at threshold 0.75, had 14 errors among examples with a non-null reference. All were false negatives in the old eval partition. Category counts: unfinished_list 4; missing_argument 3; trailing_conjunction 2; question_after_conjunction 2; statement 1; indirect_request 1; mid_word 1. Reference-null examples are excluded. That old eval partition is now development evidence and must not be described as an unseen final test for this experiment.

The targeted arm teaches that a conjunction, contrast, or embedded clause does not itself mean the utterance is unfinished: a final question, request, observation, or comparison can complete the intended meaning. Its open counterpart requires more text. The general arm supplies the same number of diverse, newly written ordinary contrasts as an added-data control.

## Composition and schema

- targeted: 320 rows / 160 groups / eight categories with 20 pairs each.
- general: 320 rows / 160 groups / eight categories with 20 pairs each.
- Each group has one provisionally ready and one provisionally wait example.
- `inputs.jsonl` contains only `id`, `group_id`, `split`, `text`, `is_final`. Every `split` is `train`; every `is_final` is true. Neither source arm nor expected readiness is encoded in input fields or IDs.
- `reference.jsonl` alone carries `arm`, `category`, `group_rank`, `arm_row_index`, readiness expectations, and provenance. These are AI-authored expectations, **not human gold labels**. They must not be passed to the teacher or used as the training targets. Independent Codex scoring is performed separately.
- IDs are deterministic hashes of the final utterance text; group IDs are opaque hashes. Pair members are presented in a seeded mixed order.
- All scenarios were individually authored. Contrast partners intentionally share a scenario. Other groups are not generated by replacing nouns in one template.

## Nested learning sizes

Within each arm, the file order is `group_rank` 1 through 160, with two adjacent rows per group. Category order cycles across all eight categories before taking the next pair from each. Select an arm using reference metadata and take its first 80, 160, or 320 rows (equivalently groups with rank at most 40, 80, or 160). All three sizes retain all pairs, equal ready/wait counts, and equal category proportions. Each smaller selection is a subset of the next. `arm_row_index` is 1-based and follows this order. Teacher submission uses a separate seeded shuffle and strips all metadata other than local IDs and text.

## Categories

Targeted: adversative_question, concessive_statement, conditional_completion, reason_request, contrast_choice, discourse_completion, embedded_completion, indirect_completion.

General: direct_question, explicit_instruction, complete_observation, plans_and_preferences, list_closure, self_correction, time_quantity, social_and_resolved_reference.

## Review and limitations

All 320 wait texts were reviewed before independent teacher labeling. Initial truncation boundaries sometimes formed complete elliptical questions such as a trailing `〜のは`, closed lists with only a redundant count omitted, or a complete imperative ending in `〜して`. Four initial boundaries, then 96 broader boundaries, then six final imperative boundaries were revised (106 edits affecting 104 distinct rows). Changes either move the cut earlier or use a different unfinished utterance in the same scenario; not every pair is therefore an exact prefix/completion pair. Ready examples were unchanged.

Speech prosody and conversational context can change whether a short response is appropriate. The reference booleans remain provisional despite review. Teacher disagreement is evidence to inspect, not an automatic error, and the independent teacher scores—not reference booleans—must train the students.

Exact and punctuation-normalized overlap with the old 240 inputs is zero. Internal exact duplicates are zero. A character-trigram-set Jaccard screen at 0.55 flagged no cross-group or old/new pairs. Within-group contrasts are deliberately excluded. This lexical screen does not prove semantic independence. Validation details and the full pre-labeling text-change history are in `validation.json`.
