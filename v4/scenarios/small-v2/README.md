# small-v2（台本 第2版）

## v1 との違い

- **T1、T2、T3、T4**: `scenarios/small`（v1）と同じ。
- **T5（長い語り、5 件）**:
  - 途中の無音（`[pause 0.7]`）の前を、すべて句点（`。`）の言い切りにするのではなく、「〜んだけど、」「〜てね、」「〜たら、」「〜し、」「〜から、」のような**話が続く形**にした。
  - 1 件あたり 1〜2 か所だけ、聞き手が「うん」と相づちを打ちたくなる文の切れ目（「〜だったんだよね。」「〜してくれたんだよ。」など）を残した。
  - 最後の文は、問いかけや「〜よね。」「〜って話。」など、話がはっきり終わる形にした。
- **C2（複数ターンの質問、10 件）**:
  - 1 つ目の発話の文の途中に、話を続ける形の区切り（「〜んだけど、」「〜てね、」「〜から、」など）と `[pause 0.6]` を入れた。
  - 2 つ目の発話（質問）と `expect` の答えは v1 と同じ。

## 変更の理由

MaAI（声の抑揚や韻律から「話がまだ続くか・言い終わったか」と「相づちを打つ機会」を予測するモデル）を適切に動かし、評価できるようにするため。

v1 では長い語り（T5）や複数の文（C2）の途中の無音が毎回「。」（言い切り）のあとに置かれていたため、合成音声の抑揚も文末の言い切りになり、話の継続と終了の区別や自然な相づちの予測を測りにくかった。人が話し続けるときの自然な区切りと、はっきり閉じる言い終わりに改めることで、発話継続の待機・相づち・ターン交替を現実に即した入力で検証できるようにした。
