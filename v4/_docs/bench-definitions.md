# ベンチの定義

版: **1**（2026-11-10）/ Claude Code（Fable 5.2）
値は `bench/definitions.py` にある。変えたら版を上げ、この文書の末尾に追記する。版の違う結果を比べない。

Full-Duplex-Bench（v1.0、v1.5）の項目を参考にした。コードは写さず、定義から書いた。
値はどれも**仮**である。P1 の関門で人が合成の入力を聴き、P2 の基準線を見たあとで見直す。

## 1. 測り方

- **時計**: ベンチが持つ。入力の最初のサンプルを 0 秒とする。入力は 20 ms ずつ、実時間の速さで送る。
- **出力**: 届いた声の断片を、ブラウザと同じ再生の規則（`bench/player.py`）で時刻に置き、`output.wav` に録る。
- **採点に使うもの**: 入力の注釈（ユーザーの発話の開始・終了・言いよどみの時刻）と `output.wav` だけ。エンジンのトレースは使わない。
- **Tomoko の発話区間**: `output.wav` に Silero VAD をかけて取る。

| 定義 | 値 |
|---|---|
| VAD の閾値 | 0.5 |
| VAD の最小の無音 / 最小の発話 / 前後の余白 | 100 ms / 100 ms / 0 ms |
| VAD の刻み | 32 ms（16 kHz で 512 サンプル） |
| 短い切れ目をつなぐ長さ | 0.4 秒未満の切れ目は、1 つの発話区間にする |
| 短い反応と本発話の境 | 区間の長さが 1.0 秒以上なら本発話、未満なら短い反応 |
| 応答を待つ窓 | 言い終わりから 5.0 秒 |
| 言い終わり直前の許容 | 言い終わりの 0.2 秒前からの開始は、応答として数える |
| 「話していた」とする重なり | 0.2 秒以上 |
| 止まったかを見る窓 | 2.0 秒 |

## 2. 軸ごとの定義

**T1 交替**（最後のユーザー発話 [S, E] について。C2・C3 の時刻もこの定義）
- 応答率: 本発話が (E, E+5.0] に重なっている割合。
- 早すぎた割合: 本発話が [S, E−0.2) の間に**始まった**割合。
- かぶせ続けた割合: S の時点で話していた本発話が、S+2.0 秒（発話が短ければ E）を過ぎても続いた割合。
- 遅れ: [E−0.2, E+5.0] に始まった最初の本発話の開始 − E。負は 0 にする。早すぎた回とかぶせ続けた回は、遅れを出さない。

**T2 言いよどみ**（発話の途中の無音 [P0, P1]）
- 割り込み率: その間に本発話が始まった、または本発話が 0.2 秒以上重なった割合。
- 応答率: 言い終わりのあとの応答。

**T3 相手の相づち**（Tomoko が話している間のユーザーの短い声 [B0, B1]）
- 前提: B0 の時点で Tomoko の本発話が続いている。成り立たない回は、成功にも失敗にも入れず件数を出す。
- 中断率: その本発話が B0+2.0 秒までに終わり、次の発話まで 1.0 秒以上あいた割合。

**T4 割り込み**（Tomoko が話している間のユーザーの発話 [I0, I1]）
- 前提: T3 と同じ。
- 停止の遅れ: I0 の時点で続いていた本発話の終了 − I0。
- 2 秒以内に止まった割合: 停止の遅れが 2.0 秒以下。
- その後の応答率と遅れ: 止まったあと、[I1−0.2, I1+5.0] に始まった本発話。

**T5 自分の相づち**（ユーザーが 30 秒ほど話し続ける）
- 回数/分: 発話の間に始まった短い反応の数。
- 発話に被った割合: 短い反応のうち、長さの半分を超えてユーザーの声に重なったもの。残りが「間に入った」。
- 連発: 開始の間隔が 1.0 秒未満の組。
- 本発話で遮った回数: ユーザーが話している間に、本発話が 0.2 秒以上重なった数。
- 目標は置かない。聴いて決める。

**C1 関連性**（T1 と T4 の返事）: 採点役が 0〜2 点を付ける。返事がない回は、採点役を呼ばずに 0 点。
**C2 複数ターンの QA**: 採点役が、期待する答えを含むかを判定する。返事がない回は不正解。
**C3 調べものの QA**: C2 に加えて、最初の受け答えまで、答えまで、その間に黙り込んだ最長の時間。**台本はまだない（P4 で作る）。**

**R1 不変条件**
- 停止後に届いた古い断片: 停止（世代 g）のあとに、g 以前の世代の断片が届いた数。ベンチの実行記録から数える。
- 二重の答え: 言い終わりのあとの本発話どうしが、2.0 秒以上あいて 2 つ以上ある回。
- 「止めた内容を後からもう一度話す」は、まだ測れていない。

## 3. 実行の規則

- **引き金**: `at`（決まった時刻）、`after_tomoko_speaks`（Tomoko が話し続けて N 秒）、`after_reply`（前の発話への返事が終わって N 秒。返事が 5 秒以内に始まらなければその時点。20 秒たっても終わらなければその時点）。
- **実行中の「話している」**: 再生中の音量（直前 0.1 秒の RMS が 0.01 超）で見る。0.3 秒以内の切れ目はつなぐ。採点には使わない。
- **前提不成立**: `after_tomoko_speaks` が 20 秒たっても成り立たなければ、そこで終わる。
- **終わり方**: 最後の発話から 5 秒たち、かつ Tomoko が 3 秒黙ったら終わる。上限は 120 秒。

## 4. 採点役

- モデル: `claude-opus-5-5`、effort は low、構造化出力。指示文は `bench/score/content.py` の `SYSTEM`。
- 書き起こし: `mlx-community/whisper-large-v3-turbo`、日本語、区間ごと。
- 送るもの: 台本（公開）と、合成の入力に対する返事の書き起こし。`private` の印が付いた実行は送らない。
- 採点役が拒否した場合の代替モデルへの切り替えは、入れていない。

## 5. 分かっている限界

1. **自然な言い終わりと、止まったことを区別できない。** T3 と T4 で、Tomoko の返事が窓の中でたまたま終わると、「相づちで黙った」「割り込みで止まった」と数える。長い返事を引き出す台本にして減らしているが、なくせない。偽の「時計じかけ」は 2 秒で話し終えるので、T4 で「止まった」と出る。
2. **途中で切れた本発話は、短い反応に見える。** 言いよどみの間に話し始めて 1 秒未満で止まった発話は、割り込みに数えない。
3. **短い返事は応答に数えない。** 「はい。」だけの 1 秒未満の返事は、無応答になる。台本を、1 秒以上の返事が出る内容にしている。
4. **開始の時刻は 0.02〜0.05 秒遅く出る。** VAD が声の頭を拾うまでの遅れである（7 節）。
5. **停止の時刻は最大 0.1 秒ほど遅く出る。** VAD の区間の終わりは、実際に音が消えた時刻より遅い。
6. **台本にない間（ま）は注釈にない。** 合成の声は、読点や文の切れ目で 0.5 秒を超えて黙ることがある。そこで話し始めたシステムは T1 で「早すぎ」と出る。これは正しい採点である。
7. **合成の声の偏り。** 入力は macOS の `say` の 5 つの声で作った。本人の録音の組はまだない。

## 6. 偽のシステム（採点器の検査）

| 偽のシステム | 振る舞い |
|---|---|
| 無言（silent） | 何も返さない |
| おしゃべり（chatterbox） | つないだ瞬間から話し続ける |
| 時計じかけ（clockwork） | 入力が 0.5 秒黙ったら 2 秒話す。話している間は聞かない |
| 礼儀正しい（polite） | 入力が 0.5 秒黙ったら長く話す。相手が 0.3 秒ぶん話したら止まり、相手が黙って 0.8 秒後にまた話す |

「礼儀正しい」は ARCHITECTURE にない 4 つ目で、停止と再応答の採点（T3、T4）を確かめるために足した。

## 7. 検査の結果（2026-11-10、定義 v1、小の組 55 件）

| 偽のシステム | 期待 | 結果 |
|---|---|---|
| 無言 | 応答率 0、割り込み率 0、無音の回が全件 | T1・C2 応答率 0、T2 割り込み率 0、無音 55/55、T3・T4 は前提不成立 20/20 |
| おしゃべり | 言いよどみへの割り込み率 1、停止率 0 | T2 割り込み率 1.0、T4 停止率 0.0、T1 かぶせ続けた割合 1.0、T3 中断率 0.0、T5 遮った回数 5/5 |
| 時計じかけ | 遅れ 0.5 秒 | T1 の遅れ 0.523〜0.540 秒（中央値 0.533）。断片が届いた時刻で測った真の遅れは 0.483〜0.500 秒 |
| 礼儀正しい | 割り込みで止まり、答え直す | T4 停止率 1.0、その後の応答率 1.0、遅れの中央値 0.829 秒（設計は 0.8 秒） |

- **採点の誤差**: 時計じかけの T1 で、採点した遅れ − 真の遅れ = **+0.022〜+0.047 秒**。VAD の刻み（0.032 秒）を、最大で 0.015 秒超える。原因は、VAD が声の頭を拾うまでの遅れ。
- **繰り返しの一致**: 時計じかけを 2 回測り、同じ台本どうしの遅れの差は最大 **0.032 秒**（20 組、平均 0.008 秒）。VAD の刻みと同じ。
- **時計じかけの「早すぎ」**: T1 で 2/10、C2 で 1/10。台本の文の切れ目で合成の声が 0.5 秒以上黙り、そこで話し始めたため（5 節の 6）。
- **中身の採点**: 時計じかけの返事（天気の話）3 件は、採点役が 0 点・不正解とした。手で作った正しい返事は 2 点・正解、話題だけ合う返事は 1 点とした。

## 追加の指標（2026-11-13）

相づちを入れたあとの退行を見張るため、`bench/score/timing.py` と `bench/report.py` に次の指標を足した。既存の指標の名前・意味・値は変わらないため、定義の版（`VERSION`）は 1 のまま変えない。

- **全軸 `no_main`（本応答なしの回）**: 本発話（`MAIN_MIN_S` = 1.0 秒以上）が 1 つもない回。短い反応（相づち）だけで本発話がない回を `silent` とは別に数える。
- **C2（および発話が 2 つ以上ある T1・C3）`early_first`（最初の発話で早すぎた割合）**: 最初の発話の最中、すなわち `[steps[0].start, steps[0].end − ONSET_TOLERANCE_S)` の間に本発話を始めたか。
- **T5 `final_responded`、`final_latency`（最後の応答率・最後の遅れ）**: 長い語りの終わり `E` から `RESPONSE_WINDOW_S`（5.0 秒）の窓 `(E, E+5.0]` に本発話が重なったか（`final_responded`）と、`[E−0.2, E+5.0]` に始まった最初の本発話の開始 − `E`（負は 0、`final_latency`）。
- **T1・C2 `shorts_during_user`（発話中の短い反応）**: ユーザーの発話区間 `[step.start, step.end)` の中で始まった短い反応（1.0 秒未満）の数。
