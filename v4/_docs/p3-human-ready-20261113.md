# P3 人間による会話確認の直前まで（2026-11-13、Codex）

## 確認してほしいこと

[会話確認ページ](../client/check.html)に5項目、約10分の手順を用意した。会話画面から開始し、普通の質問、間を空けた続き、短い／長めの相づち、明確な話題変更、自由な語りを試す。終了後は各項目の結果・相づちの頻度・長く話した後の待ち時間の許容と、おおよその試験時刻を返してもらう。

VOICEVOXの声質と以前の合成入力はユーザーが確認済みであり、再承認を求めない。本人の声で相づちと割り込みを分けられるか、待ち時間と頻度が自然かは、合成台本だけでは確定できない。P3全体の完了とはしない。
